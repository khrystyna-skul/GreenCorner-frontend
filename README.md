# GreenCorner Frontend

Простий клієнтський інтерфейс для перегляду даних з бекенду GreenCorner (Django REST Framework).

## Використані технології

* HTML5
* CSS3
* Vanilla JavaScript (Fetch API)

## Порти та адреси

* **Бекенд (Django API):** `http://127.0.0.1:8000/`
* **Фронтенд:** `http://127.0.0.1:5500/` (або `http://localhost:5500`)

## Як запустити проєкт

### 1. Підготовка та клонування репозиторію

Відкрийте термінал і виконайте команди для клонування фронтенд-репозиторію на свій комп'ютер:

```bash
git clone https://github.com/khrystyna-skul/GreenCorner-frontend.git
cd GreenCorner-frontend
```

### 2. Запуск бекенд-сервера (Django)

Для того щоб фронтенд міг отримувати дані про рослини, бекенд має бути обов'язково запущений на порту 8000:

1. Відкрийте термінал у папці бекенд-проєкту GreenCorner.
2. Активуйте віртуальне середовище та запустіть сервер:

   ```bash
   python manage.py runserver 8000
   ```

3. Переконайтеся, що API доступне за адресою: `http://127.0.0.1:8000/api/plants/`.

### 3. Запуск фронтенду

Оскільки фронтенд побудований на чистому JavaScript (Vanilla JS), додаткове встановлення залежностей через `npm install` не потрібне.

Оберіть один із двох зручних способів запуску:

#### Спосіб А: Через VS Code Live Server (рекомендовано)

1. Відкрийте папку `GreenCorner-frontend` у Visual Studio Code.
2. Встановіть розширення **Live Server** (якщо ще не встановлено).
3. Натисніть правою кнопкою миші на файл `index.html` і виберіть **"Open with Live Server"**.
4. Додаток автоматично відкриється у браузері за адресою: `http://127.0.0.1:5500/`.

#### Спосіб Б: Прямий запуск у браузері

Просто двічі клацніть лівою кнопкою миші по файлу `index.html` у провіднику файлів або перетягніть його у вікно будь-якого сучасного браузера (Chrome, Firefox, Edge).
