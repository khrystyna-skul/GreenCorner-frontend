# GreenCorner Frontend

Простий клієнтський інтерфейс для перегляду даних з бекенду GreenCorner (Django REST Framework).

## Використані технології
* HTML5
* CSS3
* Vanilla JavaScript (Fetch API)

## Порти та адреси
* **Бекенд (Django API):** `http://127.0.0.1:8000/`
* **Фронтенд:** `http://127.0.0.1:5500/` (або `http://localhost:5500`)
