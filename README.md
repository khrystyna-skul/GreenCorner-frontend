# GreenCorner Frontend

Односторінковий веб-застосунок (SPA) для перегляду та управління каталогом кімнатних рослин. Застосунок взаємодіє з бекенд-сервісом Django REST Framework за допомогою розширеної автентифікації на базі JWT.

## Використані технології
* **HTML5 & CSS3** (Адаптивна верстка, модальні вікна, системні сітки)
* **Vanilla JavaScript (ES6+)** (Fetch API, Async/Await)
* **JWT (JSON Web Tokens)** (Збереження та безшумне оновлення access/refresh токенів)
* **LocalStorage** (Збереження стану сесії користувача)

---

## Порти та адреси
* **Бекенд (Django API):** `http://127.0.0.1:8000/`
* **Фронтенд (Live Server):** `http://127.0.0.1:5500/` (або `http://localhost:5500`)

---

## Реалізований функціонал та поведінка (SPA)

Застосунок побудовано в межах одного файлу `index.html` без перезавантаження сторінок:

1. **Каталог рослин (Публічний доступ):**
   * Доступний усім відвідувачам без авторизації.
   * Витягує дані з `GET /api/plants/`.
   * Натискання на картку рослини відкриває модальне вікно з детальною інформацією (ціна, освітлення, складність, безпека для тварин, тип, родина, розплідник).

2. **Автентифікація (Логін & Реєстрація):**
   * **Реєстрація (`POST /api/auth/register/`):** Форма створення акаунта з валідацією полів та підтвердженням пароля.
   * **Логін (`POST /api/auth/login/`):** Отримання `access` та `refresh` токенів. Збереження токенів та ім'я користувача у `localStorage`.

3. **Захищена панель (Додавання рослин):**
   * Форма публікації нової рослини (`POST /api/plants/`).
   * **Захист маршрутів:** Спроба відкрити панель неавторизованим користувачем автоматично перенаправляє на екран входу з перенаправленням назад після успішного входу.
   * Авторизований користувач не має доступу до екранів входу/реєстрації (авто-редірект у каталог).

4. **Автоматичне оновлення токена (Silent Refresh):**
   * Реалізовано JS-обгортку `authFetch`. У разі отримання статусу `401 Unauthorized` під час захищених запитів, застосунок робить фоновий запит на `POST /api/auth/refresh/` для отримання нового `access`-токена і прозоро для користувача повторює початковий запит.

5. **Стан хедера & Logout:**
   * **Неавторизований:** бачить кнопки *«Увійти»* та *«Реєстрація»*.
   * **Авторизований:** бачить привітання з власним ім'ям (`Вітаємо, username!`), кнопку *«Панель додавання»* та кнопку *«Вийти»* (очищає `localStorage`).

## Як запустити проєкт

### 1. Запуск бекенд-сервера (Django)
Для роботи фронтенду бекенд обов'язково має працювати на порту **8000**:

```bash
# Перейдіть у папку бекенд-проєкту та активуйте venv
python manage.py runserver 8000
```
*Переконайтеся, що API доступне за адресою: `http://127.0.0.1:8000/api/plants/`.*

### 2. Запуск фронтенду

Додаткове встановлення залежностей через `npm install` не потрібне.

#### Спосіб А: Через VS Code Live Server (Рекомендовано)
1. Відкрийте папку з фронтендом у Visual Studio Code.
2. Переконайтеся, що в паці присутні файли `index.html` та `auth.js`.
3. Клацніть правою кнопкою миші на файл **`index.html`** та виберіть **"Open with Live Server"**.
4. Додаток автоматично відкриється за адресою `http://127.0.0.1:5500/`.

#### Спосіб Б: Прямий запуск
Двічі клацніть лівою кнопкою миші по файлу `index.html` у провіднику файлів або перетягніть його у вікно будь-якого сучасного браузера.
